Bulbapedia Web Scraping Project

Research Question - 

How are Pokemon categorized by type, and how are Pokemon described in Bulbapedia?

Why Bulbapedia?

I chose Bulbapedia because Pokemon as a franchise has been very important to my personality and interests. This website has helped me better understand the games I have enjoyed, and I am very familiar with the website.

Website: https://bulbapedia.bulbagarden.net/

Robots.txt: https://bulbapedia.bulbagarden.net/robots.txt

The scraper collects data from two types of pages:

 - The National Pokedex listing, which provides Pokemon names, Pokedex numbers, and type information.

 - Individual Pokemon pages, from which the script attempts to collect an opening paragraph.

I have collected the official National Pokedex number, name, Japanese name, type, a very brief description of the Pokemon, and a URL for easy looking. This was collected for the first ten Pokemon in the National Pokedex.
